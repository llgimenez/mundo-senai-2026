# Mundo SENAI 2026 — Sistemas Embarcados e IoT

Registro da apresentação realizada no **Mundo SENAI 2026** pela turma do curso **Técnico em Informática para Internet** (SESI SENAI Varginha - MG).

## Sobre o Projeto
Apresentamos uma **maquete de casas automatizadas com Sistemas Embarcados e Internet das Coisas (IoT)** controlada por um microcontrolador **ESP32**. Por meio de uma página web desenvolvida para o projeto, os visitantes puderam interagir na prática com os recursos de automação residencial da maquete, como acionamento de iluminação, sensores e sistema de alarme.

## O que aprendi
Durante a preparação e a apresentação para o público externo, pude aplicar na prática a integração entre desenvolvimento web e hardware embarcado (ESP32), além de exercitar a comunicação clara para explicar conceitos técnicos de IoT de forma acessível aos visitantes.
